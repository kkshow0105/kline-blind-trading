# K线盲测 · KLine Blind Trading

逐日揭示历史 K 线的人工买卖实验。默认样本为南方中证500 ETF（510500），正式区间 2018-01-02 至 2018-12-28 共 243 个交易日，另含 60 根预热日线。

## 使用

- 空仓可买入、观望或跳到下一候选，持仓可卖出或继续持有。确认当天决定后揭示下一日，历史决定不可返回修改。手机可在图上拖动、双指缩放，点按 K 线查看行情。
- 买卖按当日收盘价模拟，各计 0.03% 佣金和 0.05% 滑点。全仓、单笔持仓、人工退出。期末未平仓以收盘估值。测试完成后可揭盲、查看逐笔和原 G1 对照，或生成 PNG 成绩图。支持的手机会打开系统分享，其他设备可保存图片。
- Chrome 或 Edge 可通过地址栏的安装入口安装。iPhone Safari 中使用「分享 → 添加到主屏幕」。首次联网打开并看到「可离线使用」后，行情和应用资源已缓存。
- 进度分样本保存于当前浏览器的 IndexedDB。同源页面或安装窗口使用浏览器提供的本地存储；不同设备、浏览器、独立存储容器各自记录。页面无需账号，应用不会上传交易记录。浏览器清除站点数据会删除进度；应用内重置只作用于当前样本。

## 开发和发布

`docs/` 是可直接部署的纯静态站点。用任意静态 HTTP 服务预览，例如 `python -m http.server --directory docs`。浏览器通过 HTTPS 或 localhost 启用 Service Worker。GitHub Pages 发布源设置为 `main` 分支的 `/docs`。

替换样本时更新 `docs/data/sample.json`。字段为 `id`、`name`、`symbol`、`first`（正式第一根的零基索引）、`scale`（价格整数的除数）及 `bars`（每行依次为日期、开、高、低、收、成交量）。日期须严格递增。数据变化时使用新的 `id`，以独立保存进度。默认样本沿用原工具的新浪财经不复权快照。

发布更新时同步递增 `docs/release.json`、`docs/sw.js`、`docs/pwa.mjs` 的版本号。资源缓存按站点路径和版本隔离，更新后保留 IndexedDB。

`node --test test/engine.test.mjs` 运行规则测试。可用环境变量 `KLINE_REFERENCE` 指向同样本的本地旧版进度文件做额外复算。个人进度不属于项目文件或发布内容。

设置环境变量 `KLINE_BROWSER` 为已安装的 Edge 或 Chrome 程序路径，再运行 `node test/browser.mjs`，可在全新临时浏览器配置中测试离线、移动布局、更新、分享和重置。测试使用 Node.js 22 及以上版本。

静态站点正常操作只渲染已揭示的数据，打包的完整行情可通过浏览器开发者工具读取。重复测试同一行情可能受记忆影响，测试结果用于历史模拟。
